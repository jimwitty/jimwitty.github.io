> 本文由对话答疑整理而成：LoJax（2018 年 ESET 披露，归因 Sednit / APT28）是第一个野外 UEFI rootkit，它劫持了合法防盗软件 LoJack 的固件驻留机制，把 DXE 驱动刷进主板 SPI Flash——重装系统、换硬盘都杀不掉。本文讲清它的出身、借助 RWEverything 合法签名驱动刷固件的攻击链、SPI 写保护三道锁（BIOSWE / BLE / SMM_BWP）为何在配置不当的机器上形同虚设、Secure Boot 为何拦不住改信任根本身的攻击，以及 Boot Guard 与清除姿势。与《BlackLotus 讲透》《UEFI 讲透》互为姊妹篇。

---

LoJax 是 UEFI rootkit 这一档的开山样本：2018 年 9 月 27 日由 ESET 披露，归因于 Sednit（即 APT28 / Fancy Bear）组织。它是**第一个被证实在野外真实使用的 UEFI rootkit**——不是实验室演示，是真打在目标机器上的。它的名字是 ESET 起的：LoJack + hijack（劫持），因为它整个驻留机制是劫持一款合法防盗软件的。上一篇 BlackLotus 里说它属于"真刷固件"一档，本文把这一档讲透。

**它的出身：一款为"删不掉"而生的合法软件**

要理解 LoJax，先要理解 LoJack。LoJack for Laptops 是 Absolute Software 公司的防盗追踪软件（技术名 Computrace）：笔记本被盗后能定位、能远程锁机抹盘。它有个与生俱来的需求——**小偷重装系统，它必须活着**。所以它的做法从设计上就和 rootkit 同构：各大 OEM（联想、戴尔、惠普等）把一个 LoJack 代理模块预置进主板固件（UEFI 的 DXE 驱动），每次开机由固件检查 Windows 分区，若代理文件不在，就由固件把它写进 Windows 的 System32 并注册成服务；代理联网联系 Absolute 的服务器报到，等待失主指令。固件驻留、系统重装不掉、用户不可见——这些"防盗卖点"逐条翻译过来就是 rootkit 的需求清单。

安全界早就盯上它：2009 年 Black Hat，Core Security 的研究员 Sacco 与 Ortega 就演示过 Computrace 机制可被劫持（固件代理写入系统时不做充分校验，代理与服务器通信也可被冒充）；2014 年卡巴斯基等又做过一轮分析。结论一直悬在那里：**这是一个由厂商预装进数千万台机器固件、设计目标就是不可删除的代理框架，谁控制了它的投递端，谁就拥有固件级驻留**。Sednit 做的，就是把这套现成框架收编。

**它住在哪：真·固件档**

与 BlackLotus 住 ESP 分区（硬盘上的普通文件）不同，LoJax 的本体是一段加进主板 SPI Flash 芯片中固件映像的 DXE 驱动（DXE：固件内部的驱动分发阶段；SPI Flash：存放固件的那颗闪存芯片）。后果直接拉满：重装系统不掉、格式化硬盘不掉、**换硬盘也不掉**——只要主板还是那块主板，它就在。每次开机，固件运行到 DXE 阶段，它的驱动就跟着执行，时机比硬盘上任何文件都早。

**攻击链：四步**

**第一步，拿到管理员权限后，先摸清固件的门锁情况。**感染从 Windows 内的一个投放程序开始（同样是已入侵后的持久化动作，需要管理员权限）。它带来一个关键工具：RWEverything 的内核驱动 RwDrv.sys——一个有合法签名的硬件调试驱动，能读写任意硬件寄存器与物理内存，本是主板工程师的正经工具（签名合法的第三方工具被收编作恶，又是 BYOVD 的老戏码）。借它，投放程序去读 SPI 控制器的配置，检查固件写保护到底锁没锁。

**第二步，判定三道锁。**SPI Flash 的 BIOS 区域写入保护有三道主要锁，术语在这里一次性钉清：**BIOSWE**（BIOS Write Enable，写使能位）是开锁动作本身；**BLE**（BIOS Lock Enable，锁定使能）规定"置位 BIOSWE 必须经过 SMM 裁决"——SMM（System Management Mode，系统管理模式）是 CPU 一个对操作系统完全透明、优先级最高的特殊执行模式，固件的守门代码住在那里，操作系统看不见也摸不着；BLE 开着时，任何置 BIOSWE 的尝试都会先触发 SMI（系统管理中断）让 SMM 守门员过目。**SMM_BWP**（SMM BIOS Write Protection）更进一步：规定 BIOS 区域只允许 SMM 内部的代码写，操作系统无论如何都写不进去。此外还有 PR0–PR4 受保护范围寄存器，可以把 Flash 的指定区间直接划成只读。这套锁配齐并开启时，从操作系统刷固件在物理上就不成立——这正是设计意图。LoJax 的投放程序先逐项检查：**在配置不当的机器上（多见于较老的机型与某些厂商的默认设置），这几道锁没有全开**，门就虚掩着。

**第三步，转储固件、植入、刷回。**门虚掩着，投放程序就用 RwDrv.sys 把整份固件映像从 SPI Flash 读出来，在内存/磁盘上完成手术：把 LoJax 的 DXE 驱动加进固件映像——这个驱动是按 LoJack 的固件代理机制仿制/改造的，内含能读写 NTFS 分区的逻辑（固件本来只认 FAT，这个驱动自带 NTFS 访问能力，为的是能直接对 Windows 系统分区下手）。手术做完，再把整份映像刷回 SPI Flash。整个过程对用户无感，机器照常开关机。

**第四步，每次开机由固件把代理"种"回 Windows。**此后每次启动，DXE 阶段 LoJax 驱动执行：检查 Windows 分区里它的小代理（rpcnetp.exe）还在不在——不在就写进 System32 并配好服务，被杀软删了、甚至整个系统被重装了，它下一次开机就再种一遍，正版 LoJack 怎么做，它就怎么做。代理起来后与 Sednit 的 C2 服务器通信（域名仿冒 Absolute 正版服务器的命名），接收并投递后续载荷（Sednit 的主力后门 Zebrocy 等）。也就是说，固件层只负责"永生 + 复活"，真正的间谍活动由它复活出来的普通后门干，分工和 BlackLotus 的"bootkit + 内核组件 + 下载器"是同一个套路，只是驻留点更深一层。

**为什么三道锁没拦住：锁是可选的，而配置是厂商的**

LoJax 最值得琢磨的一点：它没有攻破任何密码学，也没有绕 SMM。它赢在**很多机器的锁压根没拧上**。SPI 写保护这套机制在芯片组里存在多年，但"是否启用、启用几道"取决于 OEM 固件的默认配置；老机型、部分厂商为了省事或兼容性，BLE、SMM_BWP 没有全开。ESET 的判断也是如此：LoJax 只能感染写保护配置不当的机器，配置正确的机器它的投放程序会判定无从下手。这与 BlackLotus 的命门形成对照：一个是"信任资产收不回来"（吊销困局），一个是"安全开关没人拧"（配置困局）——都是机制本身没错、机制之外的环节塌了。

**为什么 Secure Boot 拦不住它**

顺手钉死一个常见误解：Secure Boot 验的是固件**加载的引导文件**（ESP 上的 .efi 们），固件本体是验签链的信任根，**根自己不在被验之列**——你没法让固件验自己。LoJax 改的是根，所以 Secure Boot 开着也照样放行它种下的整条链。能管固件本体的机制是另一套：**Intel Boot Guard**（启动守卫）——CPU/芯片组在执行固件第一条指令之前，先按熔死在硬件里的密钥哈希验固件签名，签名不对直接拒绝启动；它才是给信任根再套的一层根。Boot Guard 未启用的机器，固件完整性就没有任何密码学保障，只剩写保护那几道配置锁。

**难清除，与清除的正确姿势**

- 杀毒软件、重装系统、换硬盘：全部无效，理由如前（它在主板上）。
- 操作系统内的一切"修复"都不可信：它每次开机都复活代理，你在系统里删的它下轮再种。
- 正确清除：用厂商官方固件映像重新刷写 SPI Flash；若系统内刷写通道也不可信，用编程器夹住 Flash 芯片离线刷（硬件级操作）。刷完还要逐项确认 BLE、SMM_BWP、受保护范围都已开启，否则等于给它留门。
- 检测：把机器固件转储出来与厂商同版本映像做哈希/结构比对（多出的 DXE 驱动就是铁证），CHIPSEC 框架可以自动审计写保护配置与固件完整性；TPM 度量启动的 PCR0（第一个平台配置寄存器，专门记录固件的度量值）变化也能提示固件被改过——但同样是只记不拦，事后审计才发现。

**防御清单（按性价比）**

1. **拧锁**：在固件设置与部署基线里确认 SPI 写保护全开（BIOSWE 受 BLE 约束、SMM_BWP 开启），用 CHIPSEC 定期审计——这一条直接决定 LoJax 一类攻击能不能得手。
2. **启用 Boot Guard**（采购与验收环节确认）：让固件本体有硬件验签，信任根不再裸奔。
3. **固件及时更新**：厂商更新常包含写保护配置与漏洞修复；更新本身走上一篇讲的胶囊更新通道。
4. **限制合法签名工具的滥用**：RWEverything 这类能读写硬件的签名驱动应纳入驱动黑名单管理（微软的漏洞驱动黑名单默认开启，见攻防史第六幕）。
5. **该换就换**：ESET 披露时点过名的那些写保护先天残缺的老机型，在高价值岗位上没有补救配置的余地。

**收束：两条路线，一张地图**

把 LoJax 和 BlackLotus 并排，UEFI 层攻击的完整地图就出来了：LoJax 走**改根路线**——不碰验签，直接把自己写进信任根本人，代价是必须先找到没拧锁的机器，且要为不同固件做适配，门槛高、通杀性差，所以用它的是 APT 组织对精选目标的下手；BlackLotus 走**骗根路线**——不碰固件，专骗根发出去的信任（合法签名 + 吊销滞后 + MOK 后门），通杀性强、可商品化，所以它能上论坛标价出售。一个败在配置，一个赢在生态；防守方真正的功课也不在算法里：一边是把已有的锁拧上（配置与审计），一边是让吊销跑得起（资产治理与分阶段推进）。再往外看还有 CosmicStrand、MoonBounce 等继续走改根路线的固件植入，以及把战场推向 BMC、硬盘固件的后续样本——规律还是攻防史那条：**每堵上一层，对抗就向更外、更深、更少人看的地方转移一层**。
