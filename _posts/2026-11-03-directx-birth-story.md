## ——DirectX 诞生记（一场没有许可证的曼哈顿计划）

> 体例说明：本文仿 G. Pascal Zachary《Show Stopper》的纪实笔法写成——贴身跟着人物走、以场景还原历史。主要史料包括 Michael Drummond 专为这段往事写的《Renegades of the Empire》（2000 年出版，堪称 DirectX 版的《Show Stopper》，作者拿到了三位当事人的独家采访）、David Kushner 的 id Software 传记《Masters of Doom》、Alex St. John 与 Craig Eisler 本人的回忆文章，以及历年的公开访谈。场景调度是叙事加工，人物、时间、事件均有出处。

---

### 一、可以缩放的 Doom

1995 年 4 月，加利福尼亚州圣克拉拉，计算机游戏开发者大会（CGDC）。

先要交代这是一间什么样的屋子。CGDC 是游戏开发者一年一度的行业集会，台下坐着的是全美国最有本事、也最不给任何人面子的一批程序员。他们之中相当一部分人对微软的态度不是冷淡，而是敌意：这家公司垄断了他们的桌面，却对他们的行当一无所知。更重要的是，他们清一色地鄙视 Windows。在他们看来，Windows 是给办公室准备的玩具——开窗口、画表格、每秒刷不了几帧画面。真正的游戏全都长在 DOS 上，因为只有在 DOS 里，程序员才能绕开一切中间层，把手指直接伸进显卡的显存。

台上站着一个叫 Alex St. John（亚历克斯·圣约翰）的男人。他的头衔是微软的"布道师"（evangelist）——这个岗位不写产品、不带团队，工作就是出门说服开发者站到微软这边来。他打开一个窗口。窗口里跑着《Doom》。

关于《Doom》和它背后的 id Software，下一节会整节交代。这里只需先知道一点：在 1995 年的游戏界，《Doom》就是速度与力量的度量衡本身，是 DOS 王国的国王。

然后 St. John 伸手拖住那个窗口的边框，像拉窗帘一样，把正在运行的《Doom》拉大，又缩小。

台下安静了几秒钟。

在 DOS 里，《Doom》是全屏的、独占的、神圣不可触碰的——它接管整台机器，别的程序连看都不能看它一眼。而在这个窗口里，它成了一个可以被随意摆弄、甚至可以一边跑一边改尺寸的普通对象。更要命的是，它没有变慢。

这不是魔术。这是一个代号"曼哈顿计划"的项目，用了不到四个月做出来的第一件展品。St. John 想向全场证明的只有一件事：**在 Windows 里让游戏直接操作硬件，不但可能，而且已经有人把它写出来了。**

只有他和他的两个同伙知道，这句话里有多少水分。此时是 1995 年 4 月，Windows 95 定在 8 月 24 日上市，而那个日后叫作 DirectX 的东西，连 SDK（给开发者用的开发工具包）的影子都还没有。展品跑通了，产品还不存在。

要理解这场演示为什么能让全场安静下来，得先理解那个窗口里跑的游戏，到底是什么来头。

### 二、王座上的 id：四个从杂志社出走的年轻人

故事要从路易斯安那州一个叫什里夫波特的小城讲起。

1980 年代末，那里有一家叫 Softdisk 的公司，靠出版"磁盘杂志"过活——每月把一盘装着小软件和游戏的软盘寄给订阅者。Softdisk 的游戏部门里挤着四个年轻人：程序员 John Carmack（约翰·卡马克）和 John Romero（约翰·罗梅罗）、设计师 Tom Hall（汤姆·霍尔）、美术 Adrian Carmack（阿德里安·卡马克，与 John 只是同姓）。他们领着杂志社的工资，每月按命题交活，是软件工业流水线上最不起眼的一环。

转机来自一封"粉丝来信"，而且不止一封。

德州有一家叫 Apogee 的小公司，老板 Scott Miller（斯科特·米勒）发明了一种叫"共享软件"的卖法：游戏的第一部分免费放出去随便拷贝，玩家上瘾了，再邮购后面的部分——绕开零售货架，绕开发行商，直接在玩家之间病毒式传播。Miller 听说 Softdisk 藏着几个高手，想挖人又怕打草惊蛇，于是化名好几个"粉丝"，给 Romero 写了连篇热情洋溢的来信。Romero 后来发现这些"粉丝"的信全出自同一个地址。阴谋戳穿了，但生意谈成了：四个人开始利用晚上和周末，背着 Softdisk 给 Apogee 干私活。

1990 年 9 月的一个深夜，John Carmack 捣鼓出了一个此前所有人都认为 PC 做不到的东西。当时任天堂红白机上的《超级马里奥兄弟 3》画面可以平滑地横向滚动，而 PC 没有专门的图形芯片，画面一滚就撕裂、就卡顿。Carmack 发明了一种叫"自适应图块刷新"的技术，只重绘画面边缘新进入的一小条图块，硬是在 PC 上实现了和游戏机一样顺滑的卷轴。他们连夜用这项技术把《马里奥 3》第一关在 PC 上复刻了出来，第二天拿给任天堂看，希望能拿到官方移植的活儿。任天堂礼貌地拒绝了——但四个人看着屏幕上流畅滚动的画面，心里都清楚：他们手里握着的东西，比一份移植合同值钱得多。

同年 12 月，用同一技术做的原创游戏《指挥官基恩》（Commander Keen）通过 Apogee 以共享软件形式发布：第一章免费满世界拷贝，后两章邮购。钱像潮水一样涌进来。1991 年 2 月 1 日，四个人从 Softdisk 出走，成立 id Software——名字取自他们给自己起的外号"Ideas from the Deep"（来自深渊的想法）的缩写，去掉一个字母，又恰好是弗洛伊德心理学里"本我"（id）的拼写。这个双关，他们很得意。

接下来三年发生的事，是 PC 游戏史上密度最高的三年：

**1992 年 5 月，《德军总部 3D》（Wolfenstein 3D）。** Carmack 写了一个用光线投射技术伪造 3D 的引擎：玩家第一次以第一人称视角、在迷宫走廊里端着枪奔跑射击。此前不是没人试过第一人称，但没有人把它做到这个速度。第一人称射击（FPS）这个统治此后三十年的游戏类型，是这一年从这间小公司里诞生的。它以共享软件形式卖出了数百万份的注册量。

**1993 年 12 月 10 日午夜，《Doom》上传。** id 把共享版上传到威斯康星大学的 FTP 服务器，开放下载的头几个小时，涌入的人流直接挤垮了服务器；据当年的报道，多所大学的网络管理员发现校园网里跑的 Doom 联机流量超过了其他一切流量之和。《Doom》在《德军总部 3D》的地基上又往上盖了好几层：高低起伏的地形、明暗变化的光照、更复杂的关卡结构。更重要的是两件"周边"发明——其一是**联机死亡竞赛**（deathmatch，四名玩家在同一张地图里互相猎杀，"deathmatch"这个词就是 Romero 发明的），其二是**开放的 WAD 文件格式**：玩家可以自己做关卡、改图形，全世界几万名业余作者自发为这个游戏生产了内容。一款游戏，就这样把自己变成了一个平台。

到 1995 年，id 的王座由四根柱子撑着：

**第一根是技术的源泉地位。** 每一代 id 的引擎都重新定义"PC 游戏画面应该是什么样"，全行业都在等 Carmack 发新作，然后回头改自己的引擎。Carmack 本人在程序员群体中享有近乎宗教性的声望——他一年工作 80 小时是常态，能为省下几个 CPU 周期把一个算法重写十遍，同行对他的评价是"地球上写实时图形代码最快的人"。

**第二根是引擎授权这门军火生意。** id 不只卖游戏，还卖引擎：别家公司花几十万美元买下 id 的引擎授权，做自己的游戏（比如 Raven Software 用 Doom 引擎做的《Heretic》）。到了《Quake》时代，授权名单更长——Valve 后来做《半条命》用的 GoldSrc 引擎，源头就是 id 的 Quake 引擎授权。全行业的半壁江山，在给 id 交军火钱。

**第三根是分销的独立性。** 共享软件模式让 id 不看任何发行商和零售商的脸色：免费版在 BBS 和后来的互联网上自己传播，注册费直接汇进公司账户。十来个人的团队，年收入碾压几百人的大厂。微软高层一度认真动过干脆把 id 买下来的念头——据 Kushner 的《Masters of Doom》记载，这事在微软内部被讨论过，最终没有下文。id 不缺钱，不想卖。

**第四根是文化图腾。** Romero 是摇滚明星式的名人——长发、法拉利、派对，接受采访时口无遮拦；Carmack 则是苦行僧式的天才——同样的法拉利，只是他买回来更多是出于对机械的兴趣。人格的两极，加上"Doom 被多家公司和大学明文禁止装进办公网络，因为员工一下班全在联机互射"这类轶事，让 id 成了那个时代年轻人心目中"酷"的定义。当时圈内流传着一个让微软坐立难安的统计说法：**《Doom》的装机量，比 Windows 95 还要高。**

这就是 1995 年的局面：游戏界的王不在雷德蒙德，不在任何大公司总部里，而在德州梅斯基特一间十来个人的办公室里。王不接受觐见。王只用 DOS。

### 三、荒原：游戏为什么不在 Windows 上

王不接受觐见，有王的理由。游戏开发者拒绝 Windows，不是偏见，是算术。

DOS 是一个几乎什么都不管的操作系统：没有内存保护，没有设备抽象，游戏一启动，整台机器都是它的。它可以直接往显存里写像素，可以掐着声卡的寄存器编程，可以按扫描线的节奏组织每一帧。对办公软件来说这种"无政府状态"是灾难，对游戏来说这是唯一的活路——快一帧是一帧。

而 Windows 的设计哲学恰好站在对面。Windows 的图形系统 GDI 讲的是"设备无关"：程序只说"画一条线、贴一张图"，至于显卡是什么型号、显存怎么组织，一概不许过问，由系统慢慢翻译。这套哲学保障了同一程序在任何显卡上都能跑，代价是慢——慢到连卷轴游戏都做不了。开发者私下给 GDI 起的外号不堪入耳。微软在 1994 年 9 月推出过一个叫 WinG 的过渡库，专门给 Windows 3.x 加速贴图，它算是微软第一次承认游戏有特殊需求，《Doom》的 Windows 早期演示就和它沾过边。但 WinG 只是贴了块膏药：它加速的只是"把已经画好的画面搬上屏幕"这一步，游戏想要的全面硬件控制权，一点没给。

这就是微软 1994 年底的战略恐慌：它即将推出号称要统一一切的 Windows 95，消费市场最大的内容品类——游戏——却集体住在 DOS 里，绕过 Windows 独立存在。长此以往，家用 PC 的开机画面可能不是 Windows 的徽标，而是某个游戏开发商的菜单；而日本的任天堂、世嘉和刚刚入场（1994 年 12 月在日本发售）的索尼 PlayStation，正在客厅里把美国孩子的时间整块整块地切走。

必须有人去把游戏从 DOS 里抢回来。这个任务没有落在任何正规军团头上。它落在了三个"坏小子"身上。

### 四、三个坏小子

**Alex St. John，布道师。** 出身嬉皮士家庭——用他自己的话说，父母是 60 年代伯克利的那一代人。他不是科班出身的工程师，是微软开发者关系部门（DRG）养的一名"技术布道师"：常年泡在开发者社区里，听骂声、传话、灭火。这个位置在微软的等级体系里不高，但有一个独一无二的特权：**他比总部任何人都清楚开发者真正恨什么、要什么。**1994 年，他得出的结论是：开发者恨的不是微软，是 Windows 那堵墙；除非有人把墙拆了，否则布道词写得再动听也没用。他还从这份工作里学到了另一件事——正式渠道的请示，十有八九死于委员会。

**Craig Eisler（克雷格·艾斯勒），工程师。** 加拿大人，滑铁卢出身，正规科班。但他在加入微软之前已经小有名气：著名的 Watcom 编译器配套的 32 位 DOS 扩展器就是他写的——那是 DOS 游戏时代人人都在用的底层基础设施，也就是说，全游戏界脚下踩着的地基，有一块是他铺的。他当时在 Windows 95 的多媒体团队做游戏技术，听 St. John 说现有的技术方案开发者根本不买账，他的反应是工程师式的：那就新写一套——一套能让开发者直接够到硬件原生能力、又能让硬件厂商自由创新的 API 和驱动模型。

**Eric Engstrom（埃里克·恩斯特龙），架构师兼项目经理。** 华盛顿州乡下出身，没读完高中，父母是耶和华见证人信徒，他小时候跟着挨家挨户敲过门——用同事的话说，这段经历大概解释了他日后那种永不停歇的推销式沟通能力。他思维极快，擅长在混沌中抓住结构，Eisler 写代码时，API 规范、和厂商与开发商的对接、整个项目的进度，全压在他身上。三人为 DirectX 攒下的技术成果，后来合计拿了 11 项专利。

三个人在微软内部的名声，用《Renegades of the Empire》的书名说最贴切：帝国的叛逆者。书里记载，他们拿着塑料战斧在办公楼里横冲直撞，出席行业派对的行径几次险些酿成公关灾难；同行给他们的另一个外号是"Beastie Boys"（野兽男孩，借了当时当红说唱组合的名字）。他们是桌游《外交》和《轴心与同盟》的狂热玩家——都是那种在谈判桌上结盟、背后捅刀的游戏。

项目真正点火的那一下，据 Drummond 的书记载，来自 St. John 的一位上司——DRG 的 Segal。他对还在犹豫要不要走流程的 St. John 说了一句大意如此的话：别请示了，干。干砸了大不了被开除。

于是三个人干了一件在任何大公司都属于"违规操作"的事：**在没有立项、没有预算批文的情况下，先把项目做了起来。** 钱从 DRG 的预算里挪，St. John 动用了几十名外包合同工先行开发 SDK 的原型；项目名义上挂在多媒体部门，实际上是 DRG 在出钱、三个人在指挥。用 St. John 的话说，这笔账花出去的时候，"没有人批准过"。

1994 年 12 月 24 日，平安夜。三个人写下了这个新系统的第一批代码。

他们给项目起的代号，叫**"曼哈顿计划"**（The Manhattan Project）。

### 五、曼哈顿计划

这个代号不是随手起的。按 St. John 后来在多次访谈中的说法，曼哈顿计划的战略目标从第一天起就不只是"让 Windows 能玩游戏"——**它是要用装着 Windows 的 PC，把日本游戏主机赶出美国人的客厅。**二战时那个同名计划造出了原子弹，这个计划要造的，是 PC 游戏的核武器。三人还一度拿放射性标志当项目的 logo，直到管理层要求他们换掉。

管理层对这个名字的不安有两层：一层是品味问题——拿造原子弹的计划给游戏项目命名，过了；另一层是实打实的商业问题：日本是游戏产业的心脏，也是微软重要的市场，这个代号要是传出去，是给自己找麻烦。但三人毫不退让。Eisler 的说法是："曼哈顿计划改变了世界，好坏另说。而我们真的很喜欢核爆炸。"——他们要的恰恰是这种信号：告诉游戏开发者，这次微软来的人不是西装革履的销售，是同类。

技术上，这个"核武器"的设计图纸其实非常务实，核心是三条：

**第一，把 Direct 家族一次配齐。**DirectDraw 管 2D 画面：让游戏直接锁定显存表面、做硬件贴图和翻页——它接的是 WinG 的班，但要彻底得多。DirectSound 管声音：低延迟地把多路音效直接混进声卡，DOS 游戏最在意的那种"指哪打哪"的音响控制。DirectInput 管手柄键盘，DirectPlay 管联机对战。名字里那个统一的"Direct"，就是整个项目的宣言：不许绕路。

**第二，HAL 与 HEL 这对孪生设计。**市面上的显卡有几十种，能力参差不齐，游戏不可能为每一种各写一遍。解法是分工：HAL（硬件抽象层）由显卡厂商提供，游戏问"这个操作硬件能不能做"，能做就走硬件，快；HEL（硬件仿真层）由微软兜底，硬件做不到的操作，系统用软件模拟出来，慢一点，但保证"哪儿都能跑"。这一条看似平凡，却是 DirectX 能活下去的根基——它同时安抚了三方：开发者只写一遍代码，硬件厂商有了展示新能力的通道，玩家手上的杂牌显卡也不会被抛弃。

**第三，API 直接长在 COM 上。**DirectX 的接口用的是微软当时的组件对象模型（COM）风格——这在游戏开发者看来繁琐得要命（Carmack 一派人对此颇有微词），但它换来的是接口可以版本化演进：新版加新接口，老接口原样保留，老游戏永远能跑。对一套赌上十年寿命的基础设施来说，这个取舍后来被证明是对的。

图纸之外全是硬仗。三人带着合同工军团写代码的同时，还要一家一家去谈硬件厂商：S3、ATI、创新实验室（声霸卡的制造商）……请他们为一个尚未发布、随时可能被自家管理层砍掉的 API 写驱动。谈下来的办法和说服 id 的办法一样粗暴有效：把开发者名单拍在桌上——这些工作室都在往这边迁徙，你们不跟，下一代显卡评测里就没有你们的名字。

而在微软内部，敌人同样具体：多媒体的正统团队有自己的地盘；负责图形战略的另一支人马手握 OpenGL 和从 SGI 方向来的合作筹码，视 DirectX 为野路子；更不用说每个财季都有人问，这个没有批文的项目到底花了多少钱。曼哈顿计划在公司里的存活方式，和它在公司外一样：**不停地拿出下一个演示，让砍掉它的人找不到下嘴的时机。**

但所有这些演示里，分量最重的一件展品，不在三人手里。在德州。

### 六、说服 id

St. John 和 Carmack 打过不止一轮交道。他知道 id 的态度是整个行业的风向标，也知道 Carmack 对微软式的官僚 API 天生反感。常规布道走不通，微软最后开出的条件，堪称商业史上最直白的一次"倒贴"：

**微软出人，免费把《Doom》和《Doom II》从 DOS 移植到 Windows/DirectX 上；id 什么都不用做，移植版的全部发行权和收益，仍然归 id。**

这份报价的潜台词是：我们不要你的钱，我们只要你点头——只要"Doom 跑在 Windows 上"这句话成为事实，全行业就会自己跟过来。Carmack 同意了。

移植团队的负责人是微软的一名年轻员工，叫 Gabe Newell（盖布·纽维尔）。Newell 当时在微软做系统软件方向的项目管理，是公司第 271 号上下的早期员工之一。由他带队的好处是双重的：他既懂 Windows 的内脏，又是个骨灰级玩家，知道这个游戏一帧都不能亏待。移植工作在雷德蒙德完成，id 提供源码和最终验收。

1995 年 4 月圣克拉拉大会上那个可以随意缩放的《Doom》窗口，出处正是这个移植工程的早期成果。它要向全场传达的潜台词，开发者们都听懂了：**连 id 都已经上了这条船——或者至少，已经默许微软把船开到了他们家门口。**

移植版最终在 1996 年 8 月以《Doom 95》之名正式发售，成为**第一款正式发行的 DirectX 游戏**。从商业上说它不算大卖——玩家手里的 DOS 版早已满天飞。但它的历史定位不在销量：它是插在 Windows 阵地上的一面旗。

顺便记下 Newell 的后续，因为这条岔路日后长成了另一棵大树：1996 年，他离开微软，和 Mike Harrington 一起创办了 Valve；两年后的《半条命》用的正是 id 授权的 Quake 引擎改造版；再后来，他做了 Steam。微软为了说服 id 而派出的那名工程师，最终建起了 PC 游戏最大的分销帝国——而分销的正是跑在 DirectX 之上的游戏。这是后话。

### 七、伦敦来客：RenderMorphics 与 Direct3D 的由来

曼哈顿计划开局时有一个明显的缺口：它只有 2D。

DirectDraw 解决的是贴图和翻页，是《Doom》那一代平面加速的问题。但所有人都看得见，下一个时代是全三维的：索尼的 PlayStation 1994 年底已经在日本上市，靠的就是满屏的多边形。微软手里没有现成的 3D 游戏技术，自家从零写，来不及，也不一定是 Carmack 们认的那种东西。

1995 年 2 月，微软宣布收购一家伦敦公司：RenderMorphics。

这家公司值得整段介绍，因为它日后就是 Direct3D 的亲生母亲。RenderMorphics 1992 年成立于伦敦，创始人是三个人：Servan Keondjian（塞尔万·基翁吉安）、Doug Rabson（道格·拉布森）和 Kate Seekings（凯特·西金斯）。Keondjian 是个在英国本土游戏与计算机圈泡大的技术人，早年给 Magnetic Scrolls 这类公司做过活，对"在廉价硬件上跑出实时 3D"有近乎偏执的追求。他们的产品叫 Reality Lab——一套 3D 图形 API，设计目标非常明确：**让开发者用一套"场景图"式的接口描述三维世界，渲染又快、又能跑遍各种硬件**（有 3D 加速芯片时用芯片，没有时靠 CPU 硬扛，性能都在可接受范围内）。

在当时的实时 3D 中间件市场，Reality Lab 坐在第一梯队里。它身边的两个对手也值得记名：Criterion Software 的 RenderWare，和 Argonaut Software 的 BRender——三家英国公司，瓜分了 90 年代中期游戏业的 3D 引擎外包市场。Reality Lab 的名声来自两点：一是快，二是它真的已经在给游戏和专业图形（医学影像、CAD 等领域）供货，还在往 PlayStation、世嘉土星等主机平台上移植。一句话，它是当时市面上**可以直接买到的、最像样的 PC 实时 3D 引擎**。

微软买下它，要的不是产品，是三样东西：现成的技术、现成的团队、以及最重要的——**时间**。RenderMorphics 整个团队并入微软，Reality Lab 被改造为 Direct3D。

但这次收购从一开始就埋了一道裂缝，日后困扰了 Direct3D 好多年。裂缝的名字叫**"保留模式"与"立即模式"之争**：

- Reality Lab 原生是**保留模式**（Retained Mode）：开发者把场景交给系统保管，系统内部自己组织数据、决定怎么画。接口友好，适合快速开发，但控制权在系统手里。
- 而 Carmack 那类顶尖引擎程序员要的是**立即模式**（Immediate Mode）：什么都别替我保管，我逐帧把三角形直接喂给你，画完拉倒。繁琐，但每一分性能都攥在自己手里。

微软的 Direct3D 初版两样都塞了进去：Reality Lab 改造出保留模式，同时新写一套立即模式。结果两边都不讨好——保留模式被高手嫌弃是个玩具，立即模式初版又设计得笨拙（臭名昭著的"执行缓冲"机制，开发者要先把绘制命令攒成一坨缓冲区再提交，连 id 的人都公开抱怨过）。Keondjian 在微软待了几年后离开，后来与 Rabson 另行创业。这道裂缝要到几年后 Direct3D 砍掉保留模式、立即模式脱胎换骨，才算愈合。

1996 年 6 月，Direct3D 随 DirectX 2.0 正式登场，比 2D 家族晚了整整九个月。曼哈顿计划的版图至此才算拼全——而它登场时面对的战场，比 2D 那边还要拥挤：SGI 的 OpenGL 盘踞在专业图形和高性能一端，另一家叫 3dfx 的新公司刚推出的 Voodoo 显卡正带着它私有的 Glide 接口横扫游戏市场。这些都是后话，先回到 1995 年的那个夏天。

### 八、死线

曼哈顿计划真正的敌人，从来不是某个竞争对手，而是日历。

Windows 95 的上市日 1995 年 8 月 24 日是盖茨押上全公司声誉的日子，微软为此砸下了史上最大规模的营销战，一天都不可能挪。而 DirectX 的死线比它还要再拧紧一格：游戏行业的钱大半在圣诞季，开发商最迟要在夏天拿到稳定的 SDK，才能把游戏做完、送厂、赶在 11 月铺上货架。**SDK 每晚一个月，错过的不是一个月，是一整年。**

1995 年的春夏，雷德蒙德那间办公室的作息表接近于《Show Stopper》里 NT 团队的状态：演示一个接一个地对外放（每一次演示都是一次续命），代码一版接一版地往里填，硬件厂商的驱动问题排着队等。DirectDraw 尤其要命——它要面对市面上几十种行为各异的显卡，每一种都可能在某个翻页时序上给你翻车，而每翻一次车，就是一条"不修好就不能出货"的 show stopper。

1995 年 9 月 30 日，在 Windows 95 上市五周之后，第一版 DirectX 以 **"Windows Games SDK"** 的名义正式发布。那一年圣诞货架上的 Windows 游戏还相当单薄——游击队抢下了滩头，但滩头后面还没有大部队。

不过对三人来说，活着把东西交出来就是胜利。接下来要发生的，是这个项目从"叛逆者的私活"变成"公司的国家战略"的转折点。标志性的事件发生在一个月后的万圣节。

### 九、审判日之夜

1995 年 10 月 30 日，万圣节前夜，微软在雷德蒙德总部办了一场游戏开发者的主题活动，名字起得毫不低调：**Judgment Day，审判日。**

活动的压轴节目是一段视频。全场灯光暗下来，比尔·盖茨出现在屏幕上——穿着长风衣，端着一把霰弹枪，走在《Doom》的像素走廊里，一边走一边为 Windows 95 的游戏前景站台。这是合成的宣传短片，画面荒诞，全场爆笑。这段影像后来成了互联网时代反复流传的经典片段。

但把它放回 1995 年的语境里，它一点都不好笑——它是权力的公开交接。这家公司最顶端的那个寡言的、以商业软件为本命的人，用自己的形象给"Windows 即游戏平台"做了背书。从这一夜起，曼哈顿计划不再是三个叛逆者从别人预算里偷出来的私活。DirectX 成了国家项目。

有意思的是，也正是从这个时候起，DirectX 开始被一点点从它的三个创始人手里拿走。国家项目有国家项目的规矩：流程、合规、对外言行。三个坏小子在行业派对上的那些行径——塑料战斧已经是小事，据《Digital Antiquarian》的游戏史专栏记载，还有请花花公子女郎到派对上挑"奴隶"、放任以出格著称的舞台乐队 GWAR 带着不雅道具入场之类的场面——在游戏媒体的小圈子里是美谈，一旦捅出圈，就是丑闻。1997 年起，三人相继离开一线：St. John 于 1997 年离开微软，次年创办了自己的游戏公司 WildTangent；Eisler 和 Engstrom 后来辗转去了 AOL 掌管移动业务。Engstrom 2020 年 12 月去世，享年未满六十。给他们立传的那本书的副标题说得克制而准确：**一场崛起、一次坠落，和也许的一场凯旋。**

DirectX 本人则留了下来，开始了它的长征。

### 十、迭代长征：从游击队产品到行业地基

**1996 年，补上 3D。**DirectX 2.0（6 月）带来 Direct3D，如前文所说，双模式、口碑两极。同年 9 月的 DirectX 3.0 继续修补，保留模式开始被边缘化。一个在玩家中流传甚广的冷知识发生在这段时间：**DirectX 4 从来没有存在过。**据 Raymond Chen 后来的解释，3.0 之后微软并行开发了 4 和 5 两个版本——4 是小步快跑的过渡版，5 是大版本；结果开发者对 4 毫无兴趣，微软干脆把它的内容并入 5，版本号直接从 3 跳到了 5（1997 年）。一个幽灵版本号，成了这套 API 早期混乱生长的化石。

**1996–1999 年，两场战争。**第一场是对 3dfx 的。3dfx 是一家 1994 年成立的硅谷公司，它的 Voodoo 系列显卡是第一代真正好用的消费级 3D 加速卡，配套的私有接口 Glide 简单、快、只为自家硬件服务，一度是 3D 游戏的事实标准——那几年买显卡不认 Voodoo，等于不玩 3D 游戏。Direct3D 的对策是熬：熬硬件厂商都支持我、熬 Glide 的"只此一家"变成枷锁。2000 年，3dfx 在竞争中耗尽现金，被老对手 NVIDIA（1993 年成立、靠 RIVA 和后来的 GeForce 系列崛起的显卡公司）收购资产，Glide 随之入土。

第二场战争更著名，对手是 OpenGL 和它的旗手——又是 id，又是 Carmack。OpenGL 是 SGI（Silicon Graphics，那个年代高端图形工作站的霸主）1992 年开放出来的专业图形接口，严谨、优雅、跨平台，在专业市场根深蒂固。SGI 阵营和一部分微软内部力量原本想让 OpenGL 做 Windows 游戏的 3D 标准。1996 年底，Carmack 在他的 .plan 文件（早期极客的公开日志）里公开表态：OpenGL 更好用，Direct3D 的设计让他干活干得痛苦。1997 年，一批开发者联名发出公开信，要求微软认真支持 OpenGL 做游戏标准。同年，微软和 SGI 宣布了一个叫 Fahrenheit 的合并项目，号称要把两个 API 缝成一个——这个项目在发布会上很热闹，两年后无声无息地死了。战争的最终裁决不是靠辩论，是靠装机量：Windows 的每一台新机器都带着 DirectX，硬件厂商的每一版驱动都先保 Direct3D，开发者用脚投票。到 90 年代末，OpenGL 在游戏界退守到少数堡垒（id 自己的游戏顽固地用到 2004 年的《Doom 3》），主流王座易主。

**1999–2002 年，加冕三部曲。**DirectX 7（1999 年）引入硬件 T&L（坐标变换与光照，几何计算从 CPU 卸到显卡），NVIDIA 同年推出的 GeForce 256 自称"世界上第一款 GPU"，两件事互为表里：API 与硬件开始按同一张路线图共生。DirectX 8（2000 年）是真正的革命：**可编程着色器**登场——顶点与像素的处理不再是显卡厂商写死的固定流水线，而由开发者写小程序（shader）自定义。从这一版起，DirectDraw 被正式停止发展，2D 的江山并入 Direct3D。而 DirectX 8 的一个变体，被装进了微软的第一台主机：2001 年 11 月上市的 Xbox——"DirectX Box"的缩写，曼哈顿计划七年前在白板上写的野心，原样兑现。DirectX 9（2002 年）把这套体系推到成熟：高级着色语言 HLSL、更长的着色器、更宽的硬件普及面，它统治了此后近十年的 PC 游戏画面，是寿命最长的 DirectX 大版本。

**2006 年之后，从战争转入治理。**DirectX 10（2006 年）只支持 Vista 不向下兼容，技术上是干净的断代，商业上付出了推广迟缓的学费。DirectX 11（2009 年）靠曲面细分与计算着色器回到主流。DirectX 12（2015 年）则反过来向底层走：把内存与命令提交的控制权尽量交还给开发者——绕了一大圈，又回到了 1994 年那三个坏小子的第一性原理：**别挡路，把硬件递给开发者。**只不过这一次，说这话的是整个行业。

### 十一、它究竟靠什么登顶

把三十年压缩成机制，DirectX 的登顶不是单一技术胜利，是四股力量合流：

**其一是分发。**DirectX 寄生在 Windows 的装机量上：每一份新版 Windows 出厂自带，每一款新游戏安装时顺手更新。对开发者来说，"目标平台的用户全员有这套运行时"就是最强的 API 设计——比优雅强，比性能也强。Carmack 们在技术上赢了很多场辩论，但辩论改变不了分母。

**其二是认证的杠杆。**微软把 DirectX 兼容性写进了硬件驱动的 WHQL 认证（Windows 硬件质量实验室认证，显卡厂商要拿 Windows 兼容标识就必须过）。于是全世界的显卡厂商每个月都在为 DirectX 的新规范改驱动——这不是说服，是制度。曼哈顿计划当年要靠 St. John 一家家上门磕头的厂商关系，十年后变成了排队送审的流水线。

**其三是与硬件的共生节奏。**从硬件 T&L 到着色器到计算着色器，Direct3D 的每个大版本都和 NVIDIA、ATI（后被 AMD 收购）的新一代显卡互为发布会。API 给硬件划定赛道，硬件用性能给 API 做广告，双方一起把"只此一家"的私有接口（Glide）和"跨平台但慢半拍"的标准（OpenGL）挤到了边缘。

**其四是 Xbox 的输血。**主机业务让 DirectX 从"Windows 的附属功能"变成微软娱乐战略的中枢神经：同一套 API 横跨 PC 与主机，开发者一次学习、两处卖钱。1994 年那个狂妄的代号里写的目标——用 PC 血统的机器占领客厅——最终是靠这层共生实现的。

至于最初的对手们：DOS 早在 90 年代末就退出了历史；Glide 随 3dfx 一起入土；OpenGL 活了下来，在专业图形和后来的移动生态里继续存在，并以 Vulkan 的形式在 2016 年以"低开销新标准"的面目杀回主流——那已经是下一代人的战争了。

### 尾声：坏小子们与那个字母

最后交代几个人的下落，因为《Show Stopper》式的故事，终究是人的故事。

Alex St. John 离开微软后创办 WildTangent，把在线游戏分发做成了一门生意，后来又转战社交游戏与投资。他从不掩饰对曼哈顿计划的骄傲，在 2006 年的一次访谈里说：DirectX 的本意就是摧毁日本主机对美国游戏产业的统治，"它最后让世界上最大的软件公司做出了第一台成功的美国游戏主机——你要说这不是我们从一开始就有的野心，我可不假装谦虚。"

Craig Eisler 和 Eric Engstrom 离开微软后先一起做了一个叫 Chrome 的浏览器图形项目，没能复制第二次奇迹，之后两人去了 AOL 负责移动业务，从叛逆者变成了高管。Eisler 多年后在博客上连载过回忆 DirectX 1 到 5 的疯狂岁月；Engstrom 则在 2020 年冬天去世，游戏开发社区悼念他时用的称呼是"DirectX 之父"——三个人共享的那个称呼，被默认安在了最先走的那个人头上。

Gabe Newell 的 Steam 如今是 PC 游戏的分销中枢，运行在他当年离开的那个平台之上——从某种意义上说，曼哈顿计划播下的种子，有一株长在了微软的院子外面。

而 id Software，那个"王不接受觐见"的王：Carmack 在 2013 年离开 id 投身虚拟现实，id 几经转手后归于微软麾下（2021 年微软收购其母公司 ZeniMax）——1995 年那份"免费移植、只求点头"的报价，绕了二十六年，以另一种方式达成了并购。当年微软想买而买不到的公司，最终还是进了微软的版图，只是那时，买它的理由已经和游戏引擎无关了。

剩下那个字母。Direct 家族的成员名单几十年里来了又去：DirectDraw 死了，DirectSound 退役了，DirectPlay 早没人提了。活下来的 Direct3D 把它们的地盘尽数收编。**X** 这个当初为了占位而随手挑的字母，反而成了整个家族的姓——它先是生出了 Xbox，又在三十年后的今天，印在每一台游戏 PC 和每一台主机的开机画面里。

1994 年平安夜，三个人在没有批文的办公室里写下第一行代码时，想要的不过是让 Windows 能好好玩游戏。他们最后改变的，是"电脑应该是什么样"这件事本身。这大概就是所有 show stopper 的宿命：名单上的问题一个个被修掉之后，世界已经不是原来的那个世界了。
