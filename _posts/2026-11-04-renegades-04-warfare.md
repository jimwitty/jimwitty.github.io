> 本篇对应原书第 4 章 "Internal Warfare"（第 38–55 页）。第 3 章的内战还是抽象名词，这一章里它变成四场具体的战斗：一封给盖茨的回信、一本扔过桌子的书、一把霰弹枪，和一份白皮书。

## 本章复述

第一场战斗是打印。1993 年的某个早上，圣约翰收到一封盖茨的邮件：他在接受《信息世界》采访时公开承认，Windows 3.1 的 PostScript 打印驱动不如苹果——这在盖茨看来等于向外界承认公司技术落后。邮件里是三个问题：消息从何而来、为什么要公开讲、为什么不通过公关渠道发声。圣约翰起初以为自己要被开除，在园区里徘徊了约一小时；但愤怒很快压过恐惧——让他接受采访的正是上司，而且他的直属上司、DRG 经理 Henrich 在同一篇报道里还说过类似的话。

他直接回信反驳：如果连显而易见的问题都要否认，传道者就无法取信于人。盖茨回信称微软的技术要好十倍。圣约翰于是摆技术：Mac 更可靠、更快，是因为它生成的是二进制形式的 PostScript 数据，单位时间能传递更多信息；Windows 只能输出原始文本形式，打印图形时慢得像爬。他还不忘提醒对方：自己正是打印架构方面的专家，这话有分量。盖茨听懂了技术解释，转而去向高级顾问追责。绕过所有中层、直接和最高层打这一回合，是圣约翰此后无数次造反的原型。体制的回击随即到来：Windows 业务高级副总裁 Silverberg 亲自写信，要他停止抱怨，称驱动完全可以接受、不懂行的是他本人。最后平息风波的是 Windows 95 设计团队的项目经理 Dennis Adler（丹尼斯·阿德勒）的迂回术：他向高管们写信，称自己早已与 Adobe 谈判、准备重做有缺陷的驱动——按圣约翰的说法，阿德勒等人此前明明拒绝过 Adobe 的合作，是盖茨发火后才匆忙补救。交易很快敲定，批评被压了下去。但作者强调：这场斗争圣约翰输了面子、赢了信誉，公司内部从此把他看作敢讲真话、且观点通常正确的人。微软文化崇尚据理力争，敢于坚持的人反而得到尊重。Drummond 还插了一笔盖茨的考验法：他常假装引用某个下属的不同意见，看你是否动摇，然后笑着承认只是试探你是不是真的懂行。

第二场战斗是一本书。盖茨风波后不久，圣约翰受邀参加 NT 团队讨论平台打印支持的会议。NT 的 PostScript 驱动同样原始简陋，团队却自认做得最好。他接连追问主持会议的经理 David Snipe（大卫·斯尼普）数据压缩与格式转换的细节，在约八名开发人员与经理面前正面交锋。斯尼普说自己的架构依据的是一本 1985 年出版的 PostScript 著作——圣约翰当即从包里掏出该书的修订版，隔着桌子扔了过去：读这个新版吧，你那版已经过时六年了。几周后，斯尼普辞职；圣约翰还被请去帮忙面试他的接替者。

第三场战斗是抢地盘。1994 年，多媒体传道总监 Rick Siegel（里克·西格尔，早年是保险公司安泰的程序员，1991 年入职微软）发现了两个战场。先是多媒体：苹果的 QuickTime 已经能播放、录制和剪辑小影片，CD-ROM 能装下整部百科全书和音视频，多媒体成了个人电脑的标配，而 Windows 处理声音、影像和动画仍然糟糕；原定 1994 年夏天上市的 Windows 95（代号"芝加哥"）已推迟一年多，这个问题不解决，新系统一出生就过时。西格尔至少三次向盖茨请求资金、人力和授权，要整合分散在消费业务一侧的图形技术、推动把照片变成可漫游三维场景的技术，正面压制 QuickTime、埋葬苹果。第二个战场更大：他意识到微软忽视了一个约 50 亿美元的市场——电脑游戏。几乎所有 PC 游戏都为 DOS 而写，因为在 Windows 3.1 上跑得太慢；而游戏恰恰是消费者买电脑的重要理由。他向盖茨警告：如果让 id Software 这样的公司率先为 Windows 定下游戏标准，微软就只能被迫遵守别人的规范。一涉及编程接口的主导权，高层拨款果然迅速。可是钱一下来，项目就四分五裂：高级消费技术部搞 3D 硬件芯片，消费部门搞游戏手柄接口，NT 团队搞 3D 图形接口，各自为政、争夺同一批资源，有的从未完成，有的瞄准了错误的市场。西格尔始终没能把多媒体力量统一起来，传道者有时甚至要设法让开发者避开微软自家的半成品。

战场中央是 DOS 游戏的困境和一味叫 WinG 的药。DOS 游戏要为各种显卡、声卡的组合分别写驱动，同一款游戏在这台机器上能跑、那台就跑不了，用户花数小时调试，技术支持不堪重负；高端 UNIX 工作站早有成熟的 3D 图形语言，却没人成功移植到个人电脑——PC 游戏开发处于无标准状态。微软多媒体团队的 Chris Hecker（克里斯·赫克尔）正在开发 WinG，想提升 Windows 3.1 的游戏性能。赫克尔同样目无权威，曾在邮件里宣称代码就是自己的领地，连 Maritz 都建议把他送去学待人接物。要把 WinG 推销给以独立、叛逆、敌视微软著称的游戏开发者，需要最出色的传道者——西格尔选中了圣约翰。

此时圣约翰的个人生活正在崩塌。第二个女儿 Amelia 于 1993 年 11 月出生三周后，他不顾"两年内回缅因"的约定，坚持在雷德蒙买房（理由是楼下邻居太吵、想让妻子住得舒服些）；圣诞节他把疏远的亲戚请来，却忙得几乎不见人影，把 Kelley 一个人留在新房里照顾两个婴儿和满屋亲戚。1994 年 2 月他 27 岁生日后不久，Kelley 带着两个孩子回到缅因，后来提出离婚；他则有六个月拒绝与妻子说话。西格尔接手时的圣约翰：体重 340 多磅、留着浓密的胡子，健身敌不过公司的免费汽水和快餐。与营销副总裁 Brad Chase（布拉德·蔡斯）那种西装笔挺的形象相反，他看起来像一颗随时会爆炸的炸弹——这副模样，反而让游戏开发者觉得亲切。

他和赫克尔的冲突从见面就开始。赫克尔瞧不起这个"营销人员"，圣约翰嫌他鲁莽自大。争论的焦点是 DOS 游戏常用的逐帧翻页技术（显卡内存像翻书一样快速切换画面以形成动画）：圣约翰告诉赫克尔，微软自己的游戏团队拆解过《毁灭战士》的汇编代码，确认它用了逐帧翻页，并警告不要声张——公司不希望外界知道自己在做逆向工程。赫克尔转头就打电话给 id 的创始人 John Carmack 求证，事后还向圣约翰炫耀这通电话。尽管如此，WinG 还是推进了：1994 年 4 月，硅谷的电脑开发者大会上，团队演示了在 Windows 3.1 上运行的《毁灭战士》原型；不久微软通过 CompuServe 在线服务发布 WinG 测试版，这是微软第一次专门面向游戏开发者发布软件。评价两极分化：西格尔说这像给一架小型飞机装上喷气发动机、居然飞了起来；恩斯特罗姆说，机翼先掉了下来，机身随后也散了架。

第四场战斗是人事。游戏传道的职位被圣约翰抢走，艾斯勒耿耿于怀——他的心态被作者概括为：不要只求不输，要争取赢。圣约翰的安抚办法是先替艾斯勒造势：两人向游戏开发者做需求调查，整理出可信的愿望清单，再图入局。多媒体团队负责人 Paul Osborne（保罗·奥斯本）起初拒绝了清单的大部分内容，圣约翰便改走迂回路线：请西格尔出面去谈，并特意叮嘱绝不要提及他和艾斯勒的朋友关系；西格尔则以"赫克尔难以共事、迟早辞职"为由力荐艾斯勒接手。奥斯本最终同意。艾斯勒与赫克尔在 9 号楼——盖茨办公室旁边的 X 形大楼——共事了约八周。版本互相打架：艾斯勒自称是给赫克尔降温、熬夜跑测试推进 WinG 的人；圣约翰的回忆更夸张，说艾斯勒几乎要按住赫克尔才能让他把代码写完；西格尔说自己的任务是确保两人不互相伤害、也不互相举报。书里还有个近乎闹剧的插曲：两个人在聚餐时比拼各自的手术经历，比到全桌人都没了胃口。赫克尔本人拒绝为本书接受采访，只回了一封邮件：解释真相太费时间，他没有意愿翻旧账，哪怕这会让一些人把他写得很蠢。

高光时刻属于霰弹枪。微软在园区为行业媒体办 WinG 演示会，西格尔让圣约翰主持，还特意表示自己不想提前知道他要干什么——出事时好装不知情、还能替他打掩护。圣约翰上台先承认媒体对 Windows 的普遍看法，随后启动电脑：Windows 3.1 的蓝天白云画面与大号标志亮起，一支霰弹枪的枪管从屏幕下方缓缓升起，对准标志连开五枪，打出五个弹孔。记者们爆笑鼓掌。营销副总裁蔡斯当场脸涨得通红，认定应立刻开除圣约翰，甚至想冲上台叫停。西格尔当面顶了回去：记者们现在把你看成反派、把他看成英雄，撤掉他只会适得其反。圣约翰接着坦然承认 WinG 的代码并不优雅、只是权宜之计，但强调开发者能用它赚钱；他还练成了一套脱口秀式的主持风格，公开嘲讽微软的官僚作风和高级主管（盖茨除外），游戏开发者爱死了这个，公司内部的敌人却又多了一批。1994 年微软宣布 WinG 将内置于 Windows 95，投入数百万美元推广、免费发放开发工具包，还请来在《星际迷航：下一代》中饰演机器人 Data 的演员 Brent Spiner 站台。一场游戏会议之后，甚至有 IBM 的营销人员给西格尔寄来一面白旗。媒体也纷纷看好：《字节》杂志 1994 年 11 月断言 WinG 有望终结 DOS 的统治，《电脑零售周刊》和《电脑游戏世界》同年也都给出了乐观评价。

但高光之下，裂缝已经量过尺寸了。圣约翰和艾斯勒很快发现：WinG 只在某些图形处理上快，对游戏手柄、声卡、多人联机毫无提升；赫克尔却坚信它能让所有游戏在 Windows 上跑起来。圣约翰的判断是：WinG 只是个漂亮的演示把戏，遇到真正的游戏就会露馅，偏偏公司内部许多人并不了解这一点。1994 年 8 月，两人走访了约 30 家顶级游戏开发商，只问一个问题：微软究竟要做出什么，你们才愿意为 Windows 写游戏？他们把答案汇总成一份**白皮书**，系统列出 Windows 95 要成为成功游戏平台必须采取的步骤。不过，在向公司的游戏技术路线正式发起挑战之前，他们还需要一个人：一位项目经理。章末，两人把恩斯特罗姆从 ACT"解救"出来——他本人并不喜欢游戏，面试前只读了一本 3D 图形著作的前言、看了些截图就轻松通过了技术面试，却在项目经理 Heidi Breslauer（海迪·布雷斯劳尔）面前随口说面试"不算太有技术含量"，惹得对方怀疑他没经过严格考核；再加奥斯本对他频繁跳槽的疑虑，最后还是靠艾斯勒在"不透露三人友谊"的前提下力荐，才过关。全章收束：三位朋友，终于一起进入了盖茨的多媒体堡垒内部。

## 解读

这一章最重要的不是四场战斗谁输谁赢，而是一个反复出现的模式：**圣约翰每次都是输了政治、赢了信誉**。打印事件里查办他的是高级副总裁，救他的却是事实本身——驱动确实不如苹果，而盖茨的文化只认这一点。Drummond 借盖茨的"试探考验法"点出微软的深层规则：在这个帝国里，忠诚不值钱，**正确**才值钱；只要你次次都对，顶撞本身会被兑换成货币。这正是三人组日后敢于无证造 DirectX 的全部底气来源——他们不是不懂政治，他们是赌对了这个帝国的计价方式。

第二点是 WinG 的象征意义。它在演示台上所向披靡、在真实游戏面前处处漏风，这种"演示驱动"的胜利是微软 90 年代的典型病症：先抢下媒体与开发者的人心，产品债务以后再还。霰弹枪五枪与其说是表演，不如说是一次精准的产品定位：游戏开发者真正想要的从来不是优雅的架构，而是一个肯站在他们那边、敢嘲笑微软自己的代言人。圣约翰卖的其实不是 WinG，是信任。

最后注意章末的白皮书。它是全书的一个枢纽道具：三人组第一次不是靠表演和直觉、而是靠 30 家开发商的一手需求，向公司的技术路线提出成体系的挑战——从"造反者"向"造王者"转变的起点。以及那个还没出场的缺口：他们需要一位项目经理，也缺一样更要命的东西——一个真正的三维引擎。

## 人物与概念回收

- **Rick Siegel**：本章的组织者与保护伞。争资金、挡蔡斯、做人事迂回——没有他的庇护，三人组的造反在第一枪就会被按程序处理掉。叛逆者需要的不只是胆量，还有一个肯替他们装不知情的上级。
- **Chris Hecker**：WinG 的作者，才华与难共事程度成正比。他拒绝受访这件事本身，就是 Drummond 给读者的一课：历史由愿意开口的人书写。
- **逐帧翻页（page flipping）**：DOS 游戏动画的看家技术，显存多缓冲快速切换。微软逆向《毁灭战士》确认其用法、又秘而不宣——为了赢下游戏战争，帝国对逆向工程的态度从来是只做不说。
- **白皮书**:30 家开发商的需求清单。它将在第 16 章以另一种形态再次出现——那时它叫《The White-Paper Trail》（白皮书的踪迹），成了一份可以定罪的证据。
