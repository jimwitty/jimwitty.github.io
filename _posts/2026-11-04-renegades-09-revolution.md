> 本篇对应原书第 9 章 "Invite to a 'Revolution'"（第 137–149 页）。圣约翰出局之后，革命还得继续——只是这一次，造反者要先学会一件事：革命不只需要同志，还需要供应商、内容商，以及收购的艺术。

## 本章复述

开章点题：要发动一场席卷网络的革命，光靠微软内部的人不够，还需要一批"在街头作战的人"——愿意用新工具建设网站的外部开发者。而吸引开发者的前提，是创作工具足够简单，最好简单到像写 HTML 一样。恩斯特罗姆的打法随之清晰起来：简化 Chrome，同时出去物色现成的工具公司。这一回的处境与收购 RenderMorphics 时已完全不同：DirectX 的成功给三人组攒下了信誉，Chrome 也不再是地下项目，它将被接入浏览器、硬编码进代号"孟菲斯"的 Windows 98。

目标很快锁定：旧金山的 **Dimension X**。这家 1995 年成立的公司是第一家专做 Java 产品的初创企业，旗下有两件利器：创作工具 Liquid Motion（能做三维与多媒体网络内容，包括横幅广告和动画），以及 Java 版的 VRML 浏览器 Liquid Reality。微软此前已经授权使用过它的部分技术；整家公司约 40 人。收购它，Chrome 就等于一次性买齐了创作工具与一队人马。

但收购的真正难点不在钱，在微软内部。开发者关系部的多媒体经理正是叫停过审判日第二季的尼尔森，他在推自己的项目 **iHammer**——一款给浏览器 4.0 预备的罐装多媒体特效产品。在恩斯特罗姆眼里，iHammer 功能远不如 Dimension X 的技术，还会和 Chrome 抢同一批资源，属于重复建设。但平白扳倒一位总经理的心头好，鲁莽又徒劳。恩斯特罗姆的解法是造势：他向高层报告，太阳公司的 JavaSoft 部门只差两周就要出手收购 Dimension X，且正与山景城的 Marimba 结盟、筹划和网景合作提供同类工具。高级副总裁西尔弗伯格据此判断：哪怕估价高达 2,000 万美元，剥夺网景的潜在武器也值这个价。Drummond 把底牌挑明：恩斯特罗姆的真实目的，是借这笔收购顺手埋葬内部的 iHammer——而要做到这一点，他恰恰需要尼尔森本人的支持，于是把"支持收购"包装成"一致对外"。收购落定，Dimension X 还带来十几名一流的 Java 程序员；有杂志把 Liquid Motion 评为 1997 年最佳产品之一，行业普遍认为，微软拿到了网景没有的东西。

只是，核心团队并不都买账。首席项目经理赫德尔的不满很具体：收购决策从未征求过 Chrome 负责人的意见——我们到底需不需要、想不想要这家公司？而且交易的拉锯耗去了大量时间，有时急需找恩斯特罗姆拍板，他正埋在 Dimension X 的谈判里。更深的裂缝来自产品本身。恩斯特罗姆的胃口还在膨胀：把 Java 引进来、再加一个 Liquid Motion 的简化版 **Caffeine**，前前后后又布置了约 13 项外围任务；他为第一版 Chrome 开列的功能不少于 8 项，计划 1998 年 6 月推出。在一线写代码的赫德尔与麦卡特尼只有一个问题：这些活到底由谁来干？作者在此给恩斯特罗姆下了一个精准的判语——他有一种"现实扭曲力场"：在会议室里舌灿莲花、能把人说服一圈再说回来纯粹为了再赢一次，走出房间之后，人们却常常发现没人说得清事情具体该怎么做。功能范围之争被他写成一根棍子的拉锯：一方说太长，另一方把棍子折断、说，再量一次。赫德尔还有个小小的遗憾：圣约翰许诺过帮他拿到 THX 标志的授权，用在演示视频里——那是圣约翰出局前没有兑现的最后一件小事。

与此同时，三人组的第三角正在悄悄退出舞台中央。艾斯勒的六年婚姻在没日没夜的工作中走到了尽头，离婚的冲击让他有大约两个月几乎停摆。而他对恩斯特罗姆的不满也在积累：他发现恩斯特罗姆与圣约翰其实更像一路人——体格相仿、都没有大学学位、在学历至上的世界里都自带叛逆者的气味；艾斯勒自己则怀着更大的职业规划，越来越觉得在 DirectX 与 Chrome 的边缘地带打转无助于他的前程。他开始从核心向外漂移。

外面的浏览器大战则在这一章里正式从背景走上前台。网景发布了庞杂的 Communicator 4.0，媒体评价不错，微软的 4.0 还要等大约四个月；微软的应对是当天就发动广告闪电战，用"即将上市"去劝消费者推迟选择对手——网景 CEO 巴克斯代尔愤怒地回了一句大意是：顾客买的是产品，不是承诺。但数字不会说谎：网景的份额一年内从近 90% 跌破 70%，股价从高位 78 美元跌到 29 美元（1997 年 6 月）；微软浏览器 3.0 的份额冲到 30%。网景掉头去攻企业内联网市场，却发现自己一头撞进了微软、IBM 和太阳的地盘。而把浏览器整合进 Windows 98 的做法已经引来律师与监管者的炮火：对手指责微软借垄断地位扼杀浏览器市场。在这样的气候里，恩斯特罗姆一反 DirectX 时代的高调：Chrome 不再自称浏览器，只说是"Windows 98 的增强功能"，"网景杀手"的名头被刻意摘掉。理由很现实：在反垄断的聚光灯下，一件武器越是不像武器，活得越久。

夏末，拼图渐渐凑齐：Dimension X 入堡、XML 就位、英特尔在侧。恩斯特罗姆与艾斯勒还和团队打了个赌——若 DirectX 团队几周内交出更多可用代码，两人就剃光头；代码如期交出，两个光头如约出现。接下来缺的是外部内容。第一个被招募的是微软附近的游戏公司 **Monolith Productions**：1995 年由前海军陆战队员杰森·霍尔与六名 Edmark 出身的开发者创办（霍尔本人当过少年股票经纪人、做过黑客，创办 Monolith 的启动资金正是当年三人组给的一笔演示光盘委托）。微软这次给的合同只有 2.5 万美元，让 Monolith 基于其新游戏《Riot》建一个"镀了 Chrome 光泽"的演示网站。报酬不多，风险不小——文档缺失、漏洞成堆，最初的演示甚至根本没用到 Chrome，是用脚本和 VRML 临时拼出来的。Monolith 赌的是先发优势：按 DirectX 的经验，早期采用者能领先对手至少六个月，而用他们的话说，在互联网时间里，六个月几乎等于六年。章末，Monolith 给出全章的题眼式判断：Chrome 对网络的作用，将如同 DirectX 对 Windows 的作用。

## 解读

这一章最见功力的地方，是恩斯特罗姆的 Dimension X 收购。它本质上是一次**借外部威胁行内部清洗**的操作：太阳与网景的名字是说给高管听的，真正的刀口对着自家的 iHammer。值得注意的是，这种手法与 DirectX 时代的圣约翰式闹剧形成鲜明对照——圣约翰的权力来自声量，恩斯特罗姆的权力来自信息差与议程设置。第 6 章里路德维希那句"大炮之外还要有别的武器"，到这里算是被他的学生学成了。只是新武器也有代价：赫德尔的抱怨提醒我们，收购得来的工具和人头，并不会自动变成产品进度；管理者的胜利日，就是工程师的加班表。

第二个主题是**功能范围**。几乎每个最终失败的大型项目，墓志铭上都刻着同一句话：第一版想装下所有东西。Chrome 第一版要同时有高保真音效、二维、三维、Java、Caffeine 和另外约 13 项任务，目标硬件还是 450MHz 的不存在的电脑。棍子长短的比喻看似滑稽，实则点破了立项政治的常态：砍功能等于承认愿景缩水，在革命叙事里是政治不正确——于是没人敢当那个折棍子的人，直到时间替所有人把棍子折断。

第三，低调的改名是本章最富时代感的细节。1997 年的微软正在学习一种全新的生存技能：在反垄断的注视下推进进攻性产品。把"浏览器"改叫"操作系统增强功能"，表面是措辞游戏，实质是法律与公关对产品定义的接管。从这一章开始，Chrome 的敌人名单上，除了网景和苹果，还多了一个看不见的对手：美国司法部即将掀起的整场战争的余波。

## 人物与概念回收

- **Dimension X 与 Liquid Motion**：Chrome 工具链的来源。这家公司的命运后来与 Chrome 深度绑定——工具团队独立于核心团队的意愿被并购进来，这种"人齐了、心没齐"的整合困局，在后文中还会回响。
- **"现实扭曲力场"**：这个词更常被用来形容乔布斯；Drummond 用在恩斯特罗姆身上，是提醒读者：说服力是一种真实的生产力，也是一种真实的成本——它能让不可能的项目立项，也能让立项时的承诺在执行层无人认领。
- **艾斯勒的漂移**：三人组解体的第二阶段（第一阶段是圣约翰出局）。注意他的理由不是失败，而是**成功之后的无意义感**：DirectX 已成，Chrome 非他所愿，他的罗盘指向别处。创业团伙的散伙往往不源于争吵，而源于各自对"下一件事"的想象不再重合。
- **Monolith 与六个月领先论**：外部内容商的加入标志着 Chrome 开始复制 DirectX 的生态打法——先用小额合同和先发优势把开发者"粘"上平台。问题在于：DirectX 当年粘住开发者靠的是一个看得见摸得着的 50 亿美元市场；Chrome 能递给开发者的，只有一张关于未来的期票。
